fix(ui): correct tailwind v4 dark mode variant syntax

- Correção de sintaxe no `globals.css`. A diretiva `@variant dark { @theme }` causava falha no parse do Tailwind v4.
- Substituída por `@layer base { .dark { ... } }`, fazendo com que as classes `dark:bg-slate-900` e similares voltem a funcionar quando ativadas pelo next-themes.
